# Security policy

LCRD is a static reference-data repository and does not operate a service or
handle user accounts. Please do not include private images, personal data, or
credentials in issues or pull requests.

Report suspected malicious repository changes, compromised credentials, or
unsafe tooling privately to the repository maintainers through the GitHub
security contact for `Limnmedia/lcrd`. Do not publish sensitive details in an
issue before they are addressed.

Incorrect camera data is a data-quality issue, not a security vulnerability;
please report it through a normal issue or pull request with sources.
