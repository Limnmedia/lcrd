# Code of Conduct

LCRD is a research data project. Participants are expected to be respectful,
curious, and specific when discussing evidence or corrections.

Harassment, personal attacks, discrimination, doxxing, and deliberately
misleading provenance are not acceptable. Project maintainers may remove
content or pause participation when needed to keep collaboration safe and
evidence-focused.

For private conduct concerns, use the security contact described in
`SECURITY.md`.
