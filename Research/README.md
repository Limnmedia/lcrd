# Preserved research material

`Research/` contains historical research passes, the frozen v0.1 input, audit
notes, and source-supporting material used to build the canonical `data/`
tree. It is retained for auditability, not as a second consumer-facing
database and not as an alternative canonical source.

Do not edit a research file merely to change a canonical record. Make the
canonical change in `data/`, preserve the supporting observation and source,
and rebuild the distributions. Run `migrate` only when intentionally changing
the migration inputs. See [`LICENSING.md`](LICENSING.md) for third-party
rights boundaries.
